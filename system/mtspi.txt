# MTS Pi - optional settings. You do NOT need this file to use MTS Pi.
# Fill it in only if you want the Pi on your home Wi-Fi and reachable from your computer (to look inside,
# read the logs, update it). Edit it with any text editor, save, put the card back in the Pi and power it.
# The Pi reads it at every start. The Wi-Fi password is removed from this file once it has been applied.

# Two-letter country code of where you are (IT, DE, FR, GB, US ...). Recommended in any case.
WIFI_COUNTRY=

# Your home Wi-Fi. Without the bike nearby, the Pi joins it about a minute after power-on.
WIFI_NAME=
WIFI_PASSWORD=

# Your SSH public key (one line, starting with ssh-ed25519 or ssh-rsa). It turns on remote login as user
# "mtspi", with administrator rights:  ssh mtspi@mts-pi.local
SSH_KEY=

# Siri from the helmet: in CarPlay, hold the joystick down for one second. Experimental: it works on our bench
# and has not been proven on the road yet. Write on to try it, off to switch it off again.
SIRI=

# The card is protected against power cuts: while the Pi works nothing is written to it, so the bike can cut
# the power at any moment. Write off only when you want to change the system yourself (updates, experiments):
# the Pi restarts once and stays writable until you write on again or delete the word.
PROTECT=

# Logs are kept in memory and are gone at power-off. Write card to keep them on the card, in a partition of
# their own (useful when reporting a problem: see "Logs" in the README).
LOGS=
